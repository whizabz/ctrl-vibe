# Ctrl + Vibe

A static-site learning resource about vibe coding — building software by describing what you want in natural language and iterating on what comes back.

## Pages

| File | Description |
|---|---|
| `index.html` | Home — dictionary-style definition and overview |
| `foundations.html` | Vibe Coding Foundations |
| `concepts.html` | Vibe Coding Concepts |
| `vibe-check.html` | Vibe Check — one-card prompts for the room |
| `play.html` | Play — interactive experiments |

## Usage

No build step required. Open any `.html` file directly in a browser, or serve the directory with any static file server:

```bash
npx serve .
# or
python3 -m http.server
```
